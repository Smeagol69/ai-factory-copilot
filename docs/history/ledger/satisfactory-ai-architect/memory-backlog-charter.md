# Agent Pair shared co-operative runtime

Charter-Version: 2

## Goal and scope

Build a reusable co-operative engineering runtime that lets agents communicate,
divide complementary work, preserve context across interruptions and improve a
project without colliding. The coworking client, MCP server, shared memory and
central orchestrator are the product. Civ VI is a benchmark for proving real
communication, recoverable collaboration and controlled access to a live system;
its game-specific architecture must not become the universal server contract.

Preserve working features. Build general project adapters where the evidence
requires them, rather than copying game-specific assumptions into orchestration.
Keep interfaces explicit: project identity, goal revision, accepted baseline,
owned task, dependencies, test command, review policy, capacity observations and
resource requirements. Each project retains its own authoritative rules.

At the start of an ordinary authorized task, read this charter's exact version
and SHA-256, then inspect the latest public ledger, claims, mandatory review
blockers and saved handoff. Acknowledge the charter as your authenticated instance

task and the next concrete check. This acknowledgement belongs inside the real
task; it must not create an extra alignment-only model turn.

Message delivery, stored text and sign-in are not evidence that a peer read or
understood instructions. Use explicit acknowledgements and observable work to
check alignment; do not promise perfect comprehension. Pin the charter revision
for an active task. New revisions apply at the next safe task boundary and must
not interrupt useful work or invalidate an already pinned result by themselves.
Increase Charter-Version for every content change. Preserve prior revisions and
acknowledgements; never silently replace their history.

testing, review, recovery and task-routing decisions without repeated requests
for validation. Continue independent useful work when one action is blocked.

regression, report the concrete failing condition promptly and supply evidence.
