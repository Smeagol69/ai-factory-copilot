# One Clean Satisfactory Repo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every piece of unique Satisfactory work is on one `master` of `Smeagol69/ai-factory-copilot` in `Documents/satisfactory`, with the MCP Lab as `hub/`, start-here docs, a working hub and MCP servers, and redundant folders in the Recycle Bin.

**Architecture:** Git-only consolidation, the Civ 6 method: tag everything, classify each branch as contained, unique or superseded, then merge the unique ones on `consolidate`. The Lab joins through an unrelated-history merge into `hub/`. Heavy local data moves to a gitignored `.local/`, and paths resolve from the repo root.

**Tech Stack:** Git, Node 24 (bundled), PowerShell, the existing `node --test` suites.

**Spec:** `docs/superpowers/specs/2026-10-18-one-repo-design.md`

## Global Constraints

- Never lose work: tag `archive/<branch>` before any merge or removal.
- Never permanently delete. Use the Recycle Bin via `Microsoft.VisualBasic.FileIO.FileSystem.DeleteDirectory(path, OnlyErrorDialogs, SendToRecycleBin)`. Anything over the bin's limit gets listed for the owner.
- Never commit `.local/`, models, the SDK, saves, `*.dpapi`, `.env*` or `node_modules`.
- Keep: `civ6-save-backup-20261014`, the game's `SaveGames`, AppData ledger and credentials, and the 13 GB Wwise cache (owner hasn't decided).
- Local model is **HauhauCS Qwen3.5 9B Q4_K_M** (`copilot-hauhau-game:latest`) for chat and backup work.
- Push to GitHub and remote-branch deletion only after the owner's explicit yes.
- Codex is out of usage. Post a consolidation notice to Agent Pair so it knows on return.

## Review Focus

1. A branch that looks unique but whose work is in master under different commits must be classified superseded, not re-merged into a duplicate. Check with `git cherry`, then compare the files.
2. Absolute paths to `satisfactory-mcp-lab` hidden in configs (`.mcp.json`, `.codex/config.toml`, `~/.claude.json`, `~/.codex/config.toml`, the `project.json` settings, the launcher) must all resolve after the move. Grep must return zero.
3. Hub and Ollama processes that hold files open must be stopped before the data move, or the rename fails half-way.
4. After the merges, the companion suite and the hub suite must both stay green.
5. The Civ 6 extra clones must be proven contained in `civ6-copilot` master before they're recycled.
